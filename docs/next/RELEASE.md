## Правила PR
- Ветка от свежего `develop`, перед PR — `git pull --rebase origin develop`.
- В PR: что сделано по пунктам списка, как проверено (команда и результат), что не сделано и почему.
- Зелёные: `uv run pytest -q`, `uv run ruff check .`, `uv run mypy backend`, `cd frontend && npm run build`.
- Ни ключей, ни `.env`, ни данных кейса и снимка ЦМИ в git.
