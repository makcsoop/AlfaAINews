### 2. Вопрос-ответ и экран трассы (приоритет 1 — нужны на демо)
API готов у Р3, во фронте вызовов нет (`api.ts` знает только login/feed/card):
- `POST /api/ask` `{card_id, question}` → ответ с метками и ссылками; чужая компания — отказ.
- `GET /api/trace/{trace_id}` → `RunTrace`: шаги автомата, план, инструменты, аналитики, что убрал критик, флаги.
- `GET /api/trace/{trace_id}/cost` → ₽ и токены по шагам.
`trace_id` есть в каждой карточке. Схемы — `/docs` (OpenAPI) на запущенном бэкенде.
