## 3. Тип события от модели — только с мерой в тексте

**Проблема.** `extract --llm --limit 3` на свежих сюжетах дал `kept_llm: 0`, при этом «ВСУ совершили ракетную атаку
по гражданскому объекту в Орле…» получил от модели `supply_disruption` и стоит 5-м у заёмщика.

**Что сделать** в `backend/extract/extractor.py` / `run.py`:
- тип от модели для мер (`supply_disruption`, `tariff_duty`, `export_ban_quota`, `sanctions*`) принимать, только если
  `rules.has_measure()` находит меру в тексте, как уже сделано для санкций. Военные и криминальные новости без экономического
  объекта — `other`;
- выяснить, почему `kept_llm: 0` у подтверждённых сюжетов, в том числе у `st_c5947bc22ca5`: модель не ответила, ответ не прошёл
  проверку цитатой или его перебили правила? Записать причину в лог и в `unverified_fields`;
- расход на типирование должен быть виден в `python -m backend.llm.report` (шаг `extract`).

**Готово, когда** на базе за 48 ч в топ-10 обоих клиентов нет военных и политических новостей без экономической меры;
есть тест на 3 примера (атака, заявление политика, переговоры) — тип не `supply_disruption` и не `sanctions`;
на `--limit 5` `kept_llm > 0`.

## 4. Стенд с нуля по одной инструкции

**Что сделать.** На чистой машине (или в чистой папке с пустым volume) пройти README от начала до конца и поправить всё, что не работает:

```bash
git clone https://github.com/makcsoop/AlfaAINews && cd AlfaAINews
cp .env.example .env                                     # LLM_API_KEY вписать вручную
echo "SESSION_SECRET=$(openssl rand -hex 32)" >> .env
docker compose up -d --build
docker compose run --rm backend python -m backend.db.demo   # со снимком из п. 1
```

Проверь по шагам:
- в `.env.example` есть все переменные стенда **без значений ключей**: `LLM_API_KEY=`, `LLM_API_BASE_FALLBACK=`, `SESSION_SECRET=`,
  `LLM_MODE=live`, `TOOL_SOURCE=db`, `CARD_STORE=pipeline`, `CACHE_BACKEND=redis`, `CRITIC_LLM_ENABLED=true`, `EXTRACT_LLM=false`,
  `LABELING_ENABLED=false`;
- в образе есть `prompts/` и `config/` — без них глубокий разбор падает в заглушку;
- воркер `ingest` раз в 5 минут собирает, склеивает и извлекает факты, тратя не больше ~1 ₽ за проход;
- фронт открывается на http://localhost:3000, бэкенд на :8000, `/docs` работает.

**Готово, когда** на чистой машине по README за ≤ 15 минут поднимается лента обоих демо-клиентов с решением ЦБ в топ-3,
открывается глубокая карточка, работают вопрос-ответ и «как это получено». README описывает это нумерованными шагами,
включая раздел «если что-то не так» (нет ключа → `LLM_MODE=fixture`; нет снимка → какие команды запустить).
