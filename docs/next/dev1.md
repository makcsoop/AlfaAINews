- В `extract/run.py`, `bank/positions.py`, `knowledge/consensus.py`, `scripts/compare_extract_models.py` заменить
  `OpenAIJsonLLM(max_calls=…)` на `ClientJsonLLM(max_calls=…)` из `backend/llm/port.py` — тот же `complete_json` и `usage`.
  `purpose` → шаг бюджета: `extract`, `consensus` → `knowledge_archive`, `bank_positions` → `bank_registry`.
- Чтение `.env` из кода убрать. OCR (`transcribe_image`) — разовая подготовка, можно оставить, но пометить в README.
