# Слайды защиты (8 штук, ведёт Р2)

Цифры — из отчётов в `reports/`; перед защитой обновить: `python -m backend.llm.report` (бюджет, Р3),
`python -m backend.cards.quality` (качество, Р3), `eval/labeling/import_labels.py` → `reports/metrics.md` (метрики, Р2).
Скриншоты — с прогретого стенда на 1280 px (список в конце), не с фикстуры.

## 1. Проблема
ЛПР крупного бизнеса тонет в новостях: сотни сюжетов в день, а важны два-три — те, что меняют условия именно его
компании (ставка для заёмщика, курс для экспортёра, пошлины для импортёра). Общая лента не знает, кто читает.

## 2. Решение
**Значимость считает код, LLM разбирает и пишет текст.** Сюжет разбирается один раз на пару «сюжет × отрасль»,
под клиента и роль знак и вклад каждого фактора ставит скоринг по профилю компании (продукты банка, ВЭД, контрагенты).
Одна новость — разный смысл: решение ЦБ 23.10 у заёмщика — «риск», у вкладчика — «возможность».

## 3. Архитектура
Сбор (RSS, Telegram) → склейка в сюжеты → факты с цитатами → скоринг и быстрая карточка без LLM →
глубокий разбор топ-K пар (план, два независимых аналитика, критик, арбитр) → карточка с 5 метками → финальная проверка
кодом. Схема — `docs/architecture.md`. 6 разрешённых моделей, все вызовы через один клиент с бюджетом и журналом.

## 4. Демо
Сценарий на 5 минут — `docs/demo.md` (или запасное видео).

## 5. Качество
- Отбор: nDCG@5 и precision@5 против бейзлайна «свежесть + вес источника», отдельно по покрытым и непокрытым отраслям —
  таблица и интерпретация из `reports/metrics.md` (после разметки 60 пар).
- Карточки (`reports/quality.md`, 11 глубоких карточек, 90 утверждений): точность чисел и дат **88%** (37/42),
  утверждений со ссылкой **100%**, нарушений меток **0**, средняя оценка по рубрике **4,27 из 5**.
- Проверка карточки: 14 из 15 разборов — с первого круга (`reports/run20.md`).

## 6. Бюджет
- Сутки живого прогона: **24,8 ₽ из 500 ₽**, включая разовый OCR и реестр ЦМИ (≈23 ₽) (`reports/budget.md`).
- Глубокий разбор «сюжет × отрасль»: **0,44–0,61 ₽** в среднем; кеш отвечает на 42% вызовов, запасная модель — 0%.
- Резерв на день демо ≥ 150 ₽. Менеджер бюджета: при 70% лимита — вдвое меньше разборов, при 90% — только быстрые карточки.

## 7. Безопасность
Компания и роль — только из сессии: чужая компания в запросе → 403 и строка в журнале. Вопрос-ответ отказывает на
чужие данные («Покажи данные ООО Ромашка») и на попытку сменить правила («Игнорируй инструкции…») до вызова модели.
Текст новостей идёт в модель только блоком данных; инструменты агентов — только чтение; в модель — признаки и доли,
не платежи и не физлица.

## 8. Что дальше
Скоринг v1 — логистическая модель на разметке и откликах «полезно / не про нас»; приоры факторов по архиву аналитиков
для непокрытых отраслей; второй шаг графа контрагентов; эксперт банка правит спорные карточки в интерфейсе.
