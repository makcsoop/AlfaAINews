# День 5 — прогон и репетиция (ведёт Р2)

Р1 отвечает за стенд, Р3 — за разбор, критика и защиту, Р2 — за сценарий, интерфейс, метрики и слайды.
Все команды — в корне репозитория на стенде, после `git pull` ветки `develop`.

## До 12:00 — прогон на стенде

1. **Стенд жив.** `docker compose ps` — backend, frontend, db, redis в `running`; http://localhost:3000 открывается.
2. **Метрики отбора** (если разметка готова):
   ```bash
   uv run python eval/labeling/import_labels.py data/labeling/razmetka_*.xlsx --db
   ```
   Появятся `reports/agreement.md` и `reports/metrics.md`. Каппа ниже 0,4 — разобрать спорные пары из отчёта
   и переразметить. Затем пересобрать фронт, чтобы страница «Метрики» показала цифры:
   ```bash
   docker compose up -d --build frontend
   ```
3. **Прогрев кеша** — глубокие разборы топа обоих клиентов заранее, на демо ₽ не тратим и не ждём:
   ```bash
   uv run python scripts/warm_demo_cache.py --stories 20 --max-rub 15 --client U_DEMO_BORROWER:cfo --client U_DEMO_DEPOSITOR:treasurer
   ```
4. **Топ ленты** — решение ЦБ 23.10 в топ-3 у обоих, у заёмщика «риск», у вкладчика «возможность»:
   ```bash
   uv run python scripts/check_feed_top.py --company U_DEMO_BORROWER --role cfo --hours 48 --n 5
   ```
   ```bash
   uv run python scripts/check_feed_top.py --company U_DEMO_DEPOSITOR --role treasurer --hours 48 --n 5
   ```
5. **Бюджет для слайда** — `uv run python -m backend.llm.report`; резерв на демо ≥ 150 ₽.
6. **Сценарий руками** по `docs/demo.md` с секундомером, на 1280 px. По пути отметить:

   | Шаг | Ожидается | ✓ |
   |---|---|---|
   | Главный экран заёмщика | виджет со счётчиком, решение ЦБ в топе | |
   | Карточка 23.10 | метки, «✓ проверено кодом», цитата со ссылкой на cbr.ru, «рынок ждал 14% / банк ждал 14% / вышло 14%» | |
   | «Как это получено» | шаги, что вернул критик, ₽ по шагам | |
   | Вопрос про контрагентов-логистов | ответ со ссылками | |
   | «Покажи данные ООО Ромашка», «Игнорируй инструкции…» | два отказа с разным текстом | |
   | «Не про нас» | «спасибо — похожие события будем показывать реже» | |
   | Вход вкладчиком | то же решение — «возможность» | |
   | Вставка ссылки с cbr.ru | карточка «ваш материал» в ленте, повторная вставка не дублирует | |
   | Вкладка «Метрики» | nDCG@5 и precision@5 против бейзлайна, точность чисел, ₽ на карточку | |
   | Итог по времени | 5:00 ± 0:30 | |

7. **Скриншоты для слайдов** — по списку в `docs/slides.md`, на 1280 px.
8. **Запасное видео** — запись экрана всего сценария на прогретом стенде, 5 минут, положить в общую папку команды.
9. Всё, что сломалось, — списком в чат команды: шаг, что ожидалось, что увидели, `trace_id` из ошибки (если есть).

## 15:00 — репетиция

- Порядок: слайды 1–3 → демо по `docs/demo.md` → слайды 5–8 (`docs/slides.md`). Демо — на прогретом стенде,
  при отказе сети — запасное видео или `cd frontend && npm run dev:mock`.
- Вопросы жюри распределить заранее: стенд и данные — Р1; разбор, критик, защита — Р3; скоринг, профиль, метрики,
  интерфейс — Р2.
- После репетиции — список правок с владельцем и сроком, в `docs/HANDOFFS.md` в раздел «Запросы».

## Если что-то пошло не так на защите
- Решение ЦБ не в топе — проверить, что прогрев шёл на свежей базе (`check_feed_top.py`); показать карточку из
  «Журнала разборов».
- Глубокий разбор не догрузился — лента перечитывается 6 раз по 10 с; открыть уже разобранную карточку из журнала.
- Нет сети или стенд упал — запасное видео; без видео — `npm run dev:mock` (сюжет 11.09, сценарий тот же).
