# Как писать проект с Claude Code и не сжечь токены

## Установка (один раз, Р1 в день 1)
1. Скопировать содержимое набора в корень репозитория, дописать `.gitignore.append` в `.gitignore`.
2. Каждый разработчик: `cp CLAUDE.local.md.example CLAUDE.local.md`, вписать свой номер.
3. Положить CSV кейса в `data/raw/`, PDF ЦМИ в `data/cmi/` — Claude их не читает напрямую (запрет в `.claude/settings.json`), только через агента `data-profiler` или код.

## Что где лежит и когда загружается
| Файл | Когда попадает в контекст | Зачем |
|---|---|---|
| `CLAUDE.md` | всегда, в каждой сессии | суть, владение, инварианты, команды (< 200 строк) |
| `CLAUDE.local.md` | всегда, только у тебя | твой номер и задачи через импорт `@docs/tasks/devN.md` |
| `.claude/rules/*.md` | только когда Claude открывает файлы своей папки | правила зоны |
| `docs/*.md` | только когда Claude сам их откроет | подробности |
| `.claude/skills/*` | только по команде `/day`, `/handoff`, `/check`, `/new-task` | рабочие процессы |
| `.claude/agents/*` | в отдельном контексте агента | тяжёлая или параллельная работа |

## Первая сессия разработчика (вставить как есть)
```
/day N 1
Возьми первую задачу дня. Сначала план, потом тест на фикстуре, потом код. Работай только в моей зоне.
```

## Агенты: кто что делает
| Агент | Модель | Когда звать |
|---|---|---|
| `devN-builder` | sonnet, отдельный worktree | реализовать независимый модуль с тестом; можно 2–3 параллельно через `/new-task` |
| `prompt-smith` | sonnet | промпт и схема одного LLM-шага, проверка на фикстурах |
| `test-runner` | haiku | любой прогон тестов — в основной контекст вернётся только упавшее |
| `reviewer` | sonnet | перед коммитом: инварианты и границы зон (`/check`) |
| `data-profiler` | haiku | понять CSV, PDF, выгрузку Telegram без загрузки в контекст |
| `docs-lookup` | haiku | вопрос по библиотеке без чтения всей документации |

## Привычки, которые экономят больше всего
1. **`/clear` между задачами.** Длинная сессия пересылает всю историю с каждым запросом. Одна задача — одна сессия; перед уходом `/rename`, вернуться — `/resume`.
2. **Конкретный запрос.** «Добавь проверку цитаты rapidfuzz ≥ 90 в `backend/extract/verify.py`, тест на rate_14» вместо «доделай экстрактор». Размытые запросы запускают обход всего репозитория.
3. **План перед кодом** для задач больше одного файла (plan mode). Переделка после неверного направления стоит дороже плана.
4. **Остановись сразу**, если Claude пошёл не туда (Esc), и откатись через `/rewind`, а не уговаривай продолжить.
5. **Sonnet по умолчанию**, Opus только для сложной архитектурной развилки, Haiku — для агентов-исполнителей простых задач. Модель меняется `/model`, глубина рассуждений — `/effort` (для рутины ставь ниже).
6. **Тесты и логи — через `test-runner`.** Полный вывод pytest может стоить десятки тысяч токенов, сводка — сотни.
7. **Не давай читать большие файлы.** CSV, PDF, `node_modules`, `.venv` закрыты в настройках; данные смотрит `data-profiler`.
8. **Фикстуры вместо живых данных.** Пока нет передачи от соседа — работай на `fixtures/`. Это и быстрее, и дешевле.
9. **Следи за расходом**: `/usage` показывает расход сессии и что больше всего тратит; `/context` — что занимает контекст.
10. **Параллельно, но немного.** 2–3 агента-строителя на независимые файлы. Каждый агент — отдельный контекст и отдельный расход; больше трёх обычно не окупается.
11. **`/compact` с указанием, что сохранить**, если задача длинная и контекст подходит к пределу: `/compact сохрани текущую задачу, изменённые файлы и упавшие тесты`.
12. **Не держи сессию открытой на перерыв.** После долгой паузы кеш остывает и первый запрос пересчитывает весь контекст — лучше `/clear` и начать с `/day`.

## Ритм дня
- 10:00 — синхрон 15 минут, у каждого `/day N D`.
- В течение дня: задача → `/new-task` или одна сессия → `/check` → коммит → `/handoff`, если это передача.
- 19:00 — синхрон, обновлённый `docs/HANDOFFS.md`, остаток бюджета ключа (его сообщает Р3).

## Два бюджета, не путать
- **Токены Claude Code** — ваша подписка или API на разработку. Экономим привычками выше.
- **500 ₽ в день на общий ключ хакатона** — модели внутри продукта. Экономит менеджер бюджета, `LLM_MODE=fixture` в тестах и кеш. `prompt-smith` делает не больше 5 живых вызовов за прогон.
