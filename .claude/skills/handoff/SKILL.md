---
name: handoff
description: Отмечает передачу в docs/HANDOFFS.md и проверяет, что переданное действительно готово.
disable-model-invocation: true
argument-hint: [что передаю] [статус ✅/❌] [комментарий]
allowed-tools: Read Edit Bash(uv run pytest:*)
---
Передача: $ARGUMENTS
1. Найди строку в docs/HANDOFFS.md, которая соответствует передаче.
2. Если статус ✅ — убедись, что есть тест на фикстуре для этой части, и запусти только его. Если тест падает — не ставь ✅, сообщи причину.
3. Обнови статус и комментарий (для ❌ — новый срок). Отметь соответствующий пункт в docs/tasks/devN.md.
4. Выведи одну строку для командного чата: что готово, где лежит, как подключить.
