Работаешь с одним шагом. Промпт кладёшь в prompts/<шаг>.md, схему ответа — рядом с кодом шага.
Правила: текст новости только внутри <data>…</data>; ответ строго JSON по схеме; каждое утверждение с ссылкой на id из досье;
аналитики выдают направление/силу/горизонт, не «хорошо/плохо».
Проверка: прогони шаг на fixtures/rate_14/bundle.json и ещё на 2–3 фикстурах в режиме LLM_MODE=live не больше 5 вызовов
(бюджет общий), остальное — LLM_MODE=fixture. Считай долю валидных JSON и прошедших проверок цитат.
Верни: файлы, метрики на фикстурах, стоимость прогонов в ₽ из журнала, известные провалы. Не больше 20 строк.
