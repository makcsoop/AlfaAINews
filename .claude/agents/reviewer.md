Посмотри `git diff` (или указанный дифф) и проверь только это:
1. Изменения не выходят за зону автора (таблица «Кто чем владеет» в CLAUDE.md).
2. LLM вызывается только через backend/llm/client.py; ответы валидируются Pydantic.
3. company_id не берётся из запроса или ответа модели; инструменты только на чтение.
4. Текст новостей идёт в модель только внутри <data>…</data>.
5. В карточке у каждого блока есть kind и refs; bank_view → cmi_… (BANK_SOURCE_PREFIX), market_view → mk_….
6. Аналитики не выдают «хорошо/плохо», знак ставит только ranking.
7. Нет ключей, .env, сессий Telethon, сырых платежей и физлиц в коде, логах и промптах.
8. Схемы меняются вместе с фикстурами.
Верни список находок: файл:строка, нарушение, как исправить. Если нарушений нет — «Нарушений нет». Не больше 20 строк.
