# Данные (зона Р1)
- Сеть: 1 запрос в секунду на хост, ETag/Last-Modified, таймаут 10 с, 2 повтора с паузой.
- Каждый отброшенный материал пишется в журнал отсева с причиной.
- Даты публикации — из RSS `pubDate` или Telegram, не из HTML-мета (у ПРАЙМ мета-тег сломан). Всё в UTC.
- Любое извлечённое поле хранит дословную цитату и `item_id`; без цитаты поле не сохраняется.
- Знания аналитиков: `origin` обязателен; при чтении фильтр `published_at < story.first_seen`.
- Тексты третьих лиц клиенту не отдаём целиком: заголовок, короткая цитата, ссылка.
