# API и безопасность
- `company_id` и роль — только из сессии; параметр в запросе с чужой компанией → 403 + запись в журнал.
- Инструменты агентов — только чтение и только в рамках `company_id` сессии.
- Ошибки не раскрывают внутренности: код, короткое сообщение, `trace_id`.
