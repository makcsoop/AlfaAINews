# Интерфейс (зона Р2)
- Данные только через API (`/feed`, `/card`, `/trace`, `/ask`), без моков в продовой сборке; моки — в `frontend/src/mocks`.
- Пять меток карточки различаются цветом и подписью: факт, позиция банка, мнение рынка, вывод AI, предложение банка.
- У каждого утверждения видна ссылка на источник; у карточки — «почему вы это видите» и уверенность с причинами.
- Компоненты маленькие, без лишних зависимостей; новая npm-зависимость — только с причиной в PR.
