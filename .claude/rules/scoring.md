# Профиль и скоринг (зона Р2)
- Скоринг — чистые функции без LLM и без БД внутри; на вход Pydantic-модели, на выход число + список вкладов.
- У каждого вклада: признак, значение, ссылка на источник (`profile:…`, `analysis:…`, `bp_…`, `mk_…`).
- Знак для клиента ставится только здесь: направление фактора × знак чувствительности профиля.
- Веса и пороги — только в `config/scoring.yaml`, не в коде.
- Метрики считаются строго по времени: знания до 30.09, проверка на сюжетах октября.
