# eval

Оценка качества: разметка пар «сюжет × клиент» (`labeling/`), метрики отбора и интерпретации, отчёт качества.
Инструмент разметки — Разработчик 1 (день 3), метрики — по разделу «Метрики» финальной архитектуры.

## Как посчитать метрики (Р2)

1. Разметить пары на `/labeling` и скачать `/labeling/export.csv`.
2. Согласие разметчиков на общих парах: `uv run python -m backend.eval.agreement labels-oct-60.csv`.
3. nDCG@5 и precision@5 против бейзлайна «свежесть + вес источника», пропуски по покрытым и непокрытым
   отраслям: `uv run python -m backend.eval.metrics labels-oct-60.csv` (нужна база Р1) → `reports/metrics.md`.
